
# Real-World Retail Sales Data Analysis

## Objective
Analyze retail sales data and identify sales trends using Data Science techniques.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Steps
1. Created retail sales dataset.
2. Performed data analysis.
3. Calculated total sales.
4. Compared sales by product category.
5. Generated visualizations.

## Findings
- Total sales were analyzed.
- Best performing category was identified.
- Sales distribution was visualized.
- Quantity and sales relationship was studied.

## Conclusion
This project demonstrates how Data Science can be applied to retail business data for decision making.
